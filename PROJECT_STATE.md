## 📌 Общие сведения
- **Название приложения:** Алиса Дом: Виджет
- **Пакет:** `com.alice.homewidget`
- **Текущая версия:** `v.0.32` (`versionCode = 5`, `versionName = "0.32"`)
- **Платформа:** Android (minSdk 26 / Android 8.0+, targetSdk 34 / Android 14+)
- **Язык разработки:** Kotlin + XML RemoteViews + Material 3
- **Ключ подписи:** Фиксированный `app/debug.keystore` (пароль `android`), что позволяет обновлять новые версии APK поверх старых без удаления.
- **CI / Сборка:** Настроен сценарий GitHub Actions в `.github/workflows/build-apk.yml` для автоматической сборки `.apk` в облаке за 1.5 минуты. Артефакт: `AliceHomeWidget-v0.32-APK`.

## 🎨 Скины и темы оформления виджетов (Новое в v0.32)
Пользователь может прямо в приложении выбрать один из 3 фирменных скинов:
1. 💜 **Стиль Яндекс / Алиса (`THEME_ALICE`)**:
   - Фирменное фиолетово-сиреневое матовое стекло Glassmorphism (`bg_skin_alice.xml`), неоновая сиреневая обводка, скругление 24dp.
   - Фиолетовые полупрозрачные плитки (`bg_tile_alice.xml`), неоновые акценты (циан для влажности, лаванда для текста).
2. 🍏 **Стиль iPhone / iOS (`THEME_IOS`)**:
   - Премиальное глубокое матовое стекло Apple Frosted Glass (`bg_skin_ios.xml`) с фирменным радиусом скругления **26dp** (Apple squircle).
   - Полупрозрачные белые плитки (`bg_tile_ios.xml`), чистый системный белый шрифт (`#F5F5F7`), тонкие лаконичные разделители и SF-стиль.
3. 🤖 **Стиль Android / Material You (`THEME_ANDROID`)**:
   - Мягкая пастельная карточка Material 3 Expressive (`bg_skin_android.xml`) в приятном темном шалфейно-графитовом тоне со скруглением **28dp**.
   - Плитки Material Container (`bg_tile_android.xml`), пастельные мятно-бирюзовые акценты (`#7BD5B5`).
*Смена темы происходит мгновенно для всех размещенных на экране виджетов через `WidgetSkinHelper` без необходимости пересоздавать виджет.*

## 📱 Форматы виджетов и обновления разметки

### 1. Виджет 2 × 1 (Мини-климат) — ПОЛНОСТЬЮ ИСПРАВЛЕН
- **Проблема в прошлых версиях:** Текст комнаты и температуры наслаивался друг на друга и обрезался по высоте и ширине.
- **Решение:**
  - Полностью переверстана разметка `widget_alice_compact_2x1.xml`.
  - Убраны лишние отступы, добавлены `includeFontPadding="false"`, `singleLine="true"`, `ellipsize="end"`.
  - Оптимизированы веса: левая колонка получила гарантированные 65–70% ширины, что предотвращает сжатие текста даже на узких экранах.
  - Компактный бейдж влажности (высота ~20dp) и миниатюрная кнопка обновления 24dp.
  - Высота контента строго укладывается в 32–36dp, поэтому виджет идеально помещается в 1 строку на лаунчерах любых смартфонов (Samsung One UI, MIUI, Pixel Launcher).

### 2. Виджет 4 × 1 (Инфо-полоса) — МУЛЬТИ-УСТРОЙСТВА ИЗ РАЗНЫХ КОМНАТ
- Теперь поддерживает вывод **нескольких устройств из разных комнат** в одну аккуратную строку!
- Слот 1: Устройство / комната 1 (температура + влажность);
- Слот 2: Устройство / комната 2 (температура);
- Слот 3: Устройство / комната 3 или датчик двери (`🚪 ОК` / `🚪 ОТКРЫТО`);
- Кнопка принудительного обновления 🔄.

### 3. Виджет 4 × 2 (Главный смарт-хаб) — МУЛЬТИ-КОМНАТНЫЙ ДАШБОРД
- Позволяет выбрать устройства из любых комнат без привязки к одной комнате.
- Крупная температура и влажность основного датчика;
- Атмосферное давление (скрыто, если отключено в настройках);
- Сводные карточки датчиков из других комнат (например, Спальня, Детская);
- Статус дверей и окон;
- Заряд батареек.

### 4. Виджет 2 × 2 (Климат комнаты)
- Крупная температура (34sp), комната и шкала влажности.

## ⚙️ Персональная настройка виджетов и раздельные показатели
1. **Вкладки настройки виджетов в приложении:**
   - `[4×2 Датчики]` | `[4×1 Полоса]` | `[2×2 Климат]` | `[2×1 Мини]`.
   - Для каждого виджета запоминается свой индивидуальный набор выбранных устройств.
2. **Раздельные показатели для каждого датчика:**
   - Под каждым найденным устройством отображаются независимые чекбоксы только тех показателей, которые этот датчик физически поддерживает:
     - `[✓] Темп.` (если есть датчик температуры)
     - `[✓] Влажн.` (если есть датчик влажности)
     - `[✓] Давл.` (если есть барометр)
     - `[✓] Дверь` (если датчик открытия)
     - `[✓] Батарея` (если датчик сообщает заряд)
   - Это исключает попадание ненужных или неподдерживаемых данных на виджет.

## 🔑 Авторизация и интеграция с API Яндекса
- **Эндпоинт:** `GET https://api.iot.yandex.net/v1.0/user/info`
- **Заголовок:** `Authorization: Bearer <token>`
- **Авторизация в 1 клик:**
  - Кнопка **«➕ Создать ClientID на oauth.yandex.ru»**
  - Кнопка **«⚡ Получить токен (автоматически)»** — встроенный WebView перехватывает `access_token` и сразу начинает синхронизацию.
- **Кнопки быстрого добавления на рабочий стол:** Встроены для всех 4 размеров виджетов (`requestPinAppWidget`).

## 📂 Структура файлов проекта
- `app/src/main/java/com/alice/homewidget/`
  - `AliceApplication.kt` — запуск приложения, планирование WorkManager
  - `api/YandexApiClient.kt` — сетевые вызовы к Yandex IoT API
  - `model/YandexModels.kt` — модели данных датчиков
  - `data/WidgetDataManager.kt` — настройки темы, раздельные показатели устройств, конфигурация каждого виджета
  - `ui/MainActivity.kt` — селектор скинов, вкладки настройки виджетов, выбор показателей, пиннинг виджетов
  - `widget/`
    - `WidgetSkinHelper.kt` — хелпер цветовых схем и фонов скинов
    - `AliceHomeWidgetProvider.kt` (4x2)
    - `AliceBarWidgetProvider.kt` (4x1)
    - `AliceCompactWidgetProvider.kt` (2x2)
    - `AliceCompact2x1WidgetProvider.kt` (2x1)
  - `worker/SensorSyncWorker.kt` — фоновое обновление по расписанию
  - `receiver/BootReceiver.kt` — автозапуск после перезагрузки
- `app/src/main/res/`
  - `drawable/`
    - `bg_skin_alice.xml`, `bg_tile_alice.xml`, `bg_btn_alice.xml` (Скин Яндекс/Алиса)
    - `bg_skin_ios.xml`, `bg_tile_ios.xml`, `bg_btn_ios.xml` (Скин iPhone/iOS)
    - `bg_skin_android.xml`, `bg_tile_android.xml`, `bg_btn_android.xml` (Скин Android/Material You)
    - `ic_alice_app_icon.png` — эстетичная русская иконка приложения
  - `layout/` — разметки всех 4 виджетов и `activity_main.xml` (строго без использования тега `<View>`)
  - `xml/` — метаданные виджетов
- `.github/workflows/build-apk.yml` — облачная компиляция APK в GitHub Actions
