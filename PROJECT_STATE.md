## 🎨 Перенос на графический движок Canvas Graphics Engine (v0.34)

### Почему был осуществлен перенос (Вариант 2):
Ранее виджеты строились на вложенных XML `LinearLayout`/`TextView` в `RemoteViews`. Из-за различий в лаунчерах (MIUI, One UI, Pixel Launcher) текст обрезался по вертикали, показатели наслаивались друг на друга в виджете 2×1, а стили выглядели примитивно.

### Архитектура нового движка (`WidgetRenderEngine.kt`):
1. **Рендеринг на Canvas высокого разрешения**:
   - Вся графическая карточка виджета (фон, спекулярный стеклянный блик, плавные углы-сквирклы G2 с радиусом 26dp, кольца комфорта, статус-капсулы, типографика и микро-иконки) отрисовывается напрямую в `Bitmap` через аппаратный `Canvas` и `Paint`.
   - В `RemoteViews` передается чистый `ImageView` (`id="@+id/ivWidgetCanvas"`) с `scaleType="fitXY"`, что гарантирует **100% отсутствие наслоений, переносов строк и обрезанных шрифтов**.
2. **Математическая точность типографики**:
   - Текст измеряется через `Paint.measureText()`, `FontMetrics` и автоматический эллипсис `ellipsizeText()`. Текст идеально ложится в отведенные границы при любом разрешении экрана и плотности DPI.
3. **Интерактивные оверлеи (Transparent Ripple Hotspots)**:
   - Поверх Canvas-картинки расположены прозрачные интерактивные слои:
     - ⚙️ **Настроить этот виджет** (`@id/btnWidgetConfigure`) с системным ripple-эффектом (`bg_btn_ripple.xml`).
     - 🔄 **Мгновенное обновление** (`@id/btnWidgetRefresh`) с ripple-эффектом.
     - **Клик по виджету** (`@id/btnWidgetOpenApp`) для открытия приложения.

## 📱 Полная изоляция каждого виджета (Per-Widget Instance Isolation)

### Устранение коллизий в Android:
- **Уникальные `Uri` и `Action`**: для каждой кнопки ⚙️ на рабочем столе `PendingIntent` получает уникальный `data = Uri.parse("alice://widget/$appWidgetId")` и уникальный `action = "com.alice.homewidget.CONFIGURE_WIDGET_$appWidgetId"`. Это исключило перезапись интентов системой Android при размещении нескольких виджетов.
- **Хранение настроек strictly by `appWidgetId`**:
  - `w_${appWidgetId}_theme` — индивидуальный стиль.
  - `w_${appWidgetId}_dev_ids` — список устройств, привязанных к этому конкретному виджету.
  - `w_${appWidgetId}_title` — индивидуальное название виджета.
- Смена устройств на одном виджете **никогда не затрагивает другие виджеты**!

## 🛠️ Экран индивидуальной настройки `WidgetConfigureActivity`

- **Фильтр по комнатам (Room Filter Chips)**:
  - Горизонтальная лента чипов: «Все комнаты», «Гостиная», «Спальня», «Кухня» и т.д.
  - Позволяет легко выбирать датчики из одной или нескольких разных комнат.
- **Кастомное название виджета**:
  - Поле ввода для названия (например: «Гостиная», «Дача», «Второй этаж»).
- **Индивидуальные показатели датчиков**:
  - Каждое устройство выводит **ТОЛЬКО ТЕ показатели**, которые физически есть у датчика:
    - Температура (только если есть климат/термометр)
    - Влажность (только если есть гигрометр)
    - Давление (только если есть барометр)
    - Дверь (только если датчик открытия)
    - Батарея (только если передается заряд)
  - Лишняя и недоступная информация полностью исключена из отображения.

## 📐 Поддерживаемые форматы виджетов

1. **4 × 2 (Главный смарт-хаб датчиков)**:
   - Заголовок с комнатой и точным временем последнего обновления.
   - Левый отсек: крупная температура, круговой датчик комфорта с градиентной дугой, капсулы влажности и давления.
   - Правый отсек: плитки других выбранных комнат, статус дверей («🚪 Закрыто» / «🚪 ОТКРЫТО!») и индикатор заряда батарей.
2. **4 × 1 (Инфо-полоса нескольких комнат)**:
   - Компактная горизонтальная полоса с разделителями для вывода устройств из разных комнат в одну строчку.
3. **2 × 2 (Климат комнаты)**:
   - Квадратная карточка с большим кольцом комфорта, центральной температурой и нижней капсулой влажности.
4. **2 × 1 (Мини-климат)**:
   - Идеально выверенная узкая карточка: комната сверху, крупная температура слева, капсула влажности справа, шестеренка и обновление в углу. Никаких наслоений!

## 📂 Структура файлов проекта
- `app/src/main/java/com/alice/homewidget/`
  - `AliceApplication.kt` — запуск приложения
  - `api/YandexApiClient.kt` — сетевые вызовы к Yandex IoT API
  - `model/YandexModels.kt` — модели данных датчиков
  - `data/WidgetDataManager.kt` — хранилище настроек, изолированное по `appWidgetId`, и индивидуальные показатели устройств
  - `ui/`
    - `MainActivity.kt` — главный экран, менеджер активных виджетов, авторизация по токену и ClientID
    - `WidgetConfigureActivity.kt` — экран персональной настройки конкретного экземпляра виджета
  - `widget/`
    - `WidgetRenderEngine.kt` — Custom Canvas Graphics Engine для всех 4 форматов и 4 стилей
    - `AliceHomeWidgetProvider.kt` (4x2)
    - `AliceBarWidgetProvider.kt` (4x1)
    - `AliceCompactWidgetProvider.kt` (2x2)
    - `AliceCompact2x1WidgetProvider.kt` (2x1)
  - `worker/SensorSyncWorker.kt` — фоновое обновление по расписанию
  - `receiver/BootReceiver.kt` — автозапуск после перезагрузки устройства
- `app/src/main/res/`
  - `drawable/`
    - `bg_btn_ripple.xml` — системный ripple-эффект нажатия на хотспоты
    - `bg_skin_*.xml`, `bg_tile_*.xml`, `bg_btn_*.xml` — векторные ресурсы стилей
    - `ic_gear.xml`, `ic_refresh.xml`, `ic_humidity.xml`, `ic_thermometer.xml`, `ic_door.xml`, `ic_pressure.xml`
    - `ic_alice_app_icon.png` — эстетичная иконка приложения в стиле Алисы
  - `layout/` — разметки экранов и виджетов (Canvas ImageView + прозрачные хотспоты)
  - `xml/` — метаданные виджетов с подключением `WidgetConfigureActivity`
- `app/debug.keystore` — постоянный ключ подписи приложения
- `.github/workflows/build-apk.yml` — облачная компиляция APK в GitHub Actions (артефакт `AliceHomeWidget-v0.34-APK`)
