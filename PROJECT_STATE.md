# 🟣 Состояние и архитектура проекта: «Виджет Умного Дома Яндекс (Алиса)»

> **Этот документ предназначен для передачи полного контекста проекта при работе на любом компьютере или продолжении сессии с ИИ-ассистентом.**

---

## 📌 Общие сведения
- **Название приложения:** Алиса Дом: Виджет
- **Пакет:** `com.alice.homewidget`
- **Текущая версия:** `v.0.37` (`versionCode = 10`, `versionName = "0.37"`)
- **Платформа:** Android (minSdk 26 / Android 8.0+, targetSdk 34 / Android 14+)
- **Архитектура виджетов:** Автономный графический движок на Canvas (Custom Canvas Graphics Engine в стиле Overdrop / KWGT)
- **Ключ подписи:** Фиксированный `app/debug.keystore` (пароль `android`), что позволяет обновлять новые версии APK поверх старых без необходимости удалять приложение.
- **CI / Сборка:** Настроен сценарий GitHub Actions в `.github/workflows/build-apk.yml` для автоматической сборки `.apk` в облаке. Артефакт: `AliceHomeWidget-v0.37-APK`.

## 🚀 Ключевые изменения и исправления в v0.37

### 1. Настоящее прозрачное стекло с ребром и блюром (Apple iOS 18 Liquid Glass)
- **Прозрачность обоев рабочего стола:** Непрозрачная темная заливка заменена на кристально чистое полупрозрачное затемненное стекло (`~31–40%` opacity). Теперь сквозь виджет отчетливо видны обои рабочего стола.
- **Оптическое «ребро» стекла со спекулярным бликом:**
  - Внешний контур с многоточечным градиентным световым ребром (яркий кристальный блик `#DBFFFFFF` в верхнем левом углу, плавно сходящий к мягкому отражению).
  - Внутренняя фаска преломления (двойная кромка среза стекла) для физического ощущения толщины стеклянной пластины.
- **Эффект рассеянного света («Блюр» / Light Diffusion):**
  - Диагональный шелковистый блик рассеивания света по всей плоскости карточки.
  - Верхняя световая полка (light shelf reflection) в верхней трети виджета.
  - Мягкая естественная тень под карточкой (floating glass elevation).
- **Стеклянные внутренние модули (Pills & Sub-Cards):**
  - Подмодули и капсулы влажности/давления получили собственное полупрозрачное матовое стекло с градиентным срезом.
- **Идеальная читаемость текста на любых обоях:**
  - Типографика SF Pro дополнена деликатной контурной микротенью (`shadowLayer`), благодаря чему текст и цифры температуры гарантированно контрастны и четко видны даже на очень светлых или пестрых обоях.

## 🚀 Ранее реализовано в v0.36:

### 1. Настройка устройств перенесена исключительно в виджеты
- С главного экрана (`MainActivity`) полностью удален лишний громоздкий блок выбора устройств.
- Настройки устройств и их индивидуальных показателей теперь настраиваются строго там, где они нужны — внутри экрана настройки конкретного экземпляра виджета (`WidgetConfigureActivity`).

### 2. Полная изоляция показателей каждого виджета (Per-Widget Metric Isolation)
- Все настройки показателей датчиков теперь сохраняются под индивидуальным префиксом экземпляра виджета: `w_${appWidgetId}_dev_${deviceId}_*`.
- Добавлен метод `hasWidgetConfig(appWidgetId)`, предотвращающий случайный сброс параметров.
- Настройка или снятие галочек с показателей в одном виджете **гарантированно не затрагивает другие виджеты на рабочем столе**.

### 3. HyperOS Settings Style UI с крупными элементами и тактильными чипами
- Интерфейс настройки переведен на стиль меню настроек Xiaomi HyperOS:
  - Крупные и наглядные переключатели `MaterialSwitch` для комнат и каждого отдельного устройства.
  - Крупные тактильные капсулы (Pill Chips) для физических показателей (`🌡️ Темп.`, `💧 Влажн.`, `📊 Давл.`, `🚪 Дверь`, `🔋 Батарея`, `⛽ Уровень`, `⚡ Мощность`) с яркой подсветкой активного статуса HyperOS Cyan Teal (`#00D2B4`) и стеклянными контурами.
  - Кликабельность по всей площади заголовка комнаты и карточки устройства для быстрого переключения.

### 4. Идеальная двусторонняя синхронизация комнат, устройств и показателей
- Если в комнате включить хотя бы одно устройство — переключатель комнаты автоматически активируется (`ON`).
- При отключении устройства с него автоматически снимаются все показатели. Если в комнате не осталось включенных устройств — комната автоматически отключается (`OFF`).
- При нажатии на любой показатель устройства — устройство и комната автоматически включаются.
- При включении/выключении свитча комнаты — синхронно включаются или отключаются все входящие в нее устройства и их показатели.

### 5. Виджет 2×2: исправление наслоений, чистота текста и авто-масштабирование
- Полностью устранены наслоения данных в виджете 2×2: текстовый бейдж комфорта перенесен в открытую 90° зону нижней части кольцевого датчика, создавая запас свободного пространства более 40dp до нижней стеклянной капсулы влажности.
- Убран навязчивый огонь («🔥 Тепло») — заменен на стильные и чистые статусы («Тепло», «Комфортно», «Прохладно»).
- Динамическое авто-масштабирование заголовка комнаты: размер шрифта плавно уменьшается (с 13sp до 8.5sp), благодаря чему даже длинные названия комнат отображаются полностью.

## 🚀 Ранее реализовано в v0.35:

### 1. Устранение критического бага искажения виджета 2×2 при добавлении
- **Причина:** Ранее метод `saveAndFinish()` в `WidgetConfigureActivity.kt` вызывал обновление по всем четырём провайдерам подряд (`AliceHomeWidgetProvider` -> `AliceBarWidgetProvider` -> `AliceCompactWidgetProvider` -> `AliceCompact2x1WidgetProvider`). Провайдер `AliceCompact2x1WidgetProvider` вызывался последним и перезаписывал макет виджета 2×2 узким макетом 2×1 до тех пор, пока пользователь вручную не изменял размер на рабочем столе.
- **Решение:** Добавлена точная фильтрация через `appWidgetManager.getAppWidgetInfo(appWidgetId).provider.className`. Теперь обновляется строго соответствующий экземпляр нужного провайдера.

### 2. Фильтрация реальных показателей датчиков и устройств (включая автомобили)
- Ранее датчики определялись по эвристике `type.contains("climate")`, из-за чего неподдерживаемые устройства (например, автомобили) получали неработающую строку влажности.
- Добавлена строгая физическая валидация параметров (`hasTemperature()`, `hasHumidity()`, `hasPressure()`, `hasDoorSensor()`, `hasBattery()`, `hasWaterOrFuel()`, `hasPower()`).
- Для автомобилей и резервуаров выводится реальный уровень топлива/заряда (`⛽/🔋 Уровень`), а фиктивная влажность полностью исключена.

### 3. Группировка устройств по комнатам и двусторонняя синхронизация галочек
- В обоих экранах (`WidgetConfigureActivity` и `MainActivity`) устройства сгруппированы по комнатам с карточками комнат.
- Каждая комната имеет главный чекбокс (Master Checkbox):
  - При установке галочки на комнате — автоматически выбираются все устройства в этой комнате.
  - При снятии галочки с комнаты — все устройства комнаты отключаются.
  - При изменении галочек отдельных устройств — галочка комнаты динамически обновляется (включается, если выбраны все, снимается, если сняты все).

### 4. Кардинальный редизайн виджета 4×1 (Инфо-полоса)
- Виджет 4×1 полностью переработан: вместо мелкого однострочного текста теперь отрисовываются 3 стильные стеклянные подкарточки с акцентным скруглением.
- Крупные контрастные цифры и чёткие векторные иконки (`🌡️`, `💧`, `🚪`, `🔋`, `⛽`, `⚡`).
- Отличная читаемость на любых обоях рабочего стола.

### 5. Аутентичный Apple iOS 18 Glassmorphism
- Реализован настоящий эффект матового стекла (Frosted Glass):
  - Мультистопный диффузный градиент с шелковистым рассеиванием света.
  - Верхняя фаска спекулярного преломления с градиентом прозрачности белого контура (`LinearGradient`).
  - Вложенные полупрозрачные стеклянные подложки для информационных блоков.
- Интерактивная радужная шкала комфорта дополнена понятными бейджами («🌿 Комфортно», «❄️ Прохладно», «🔥 Тепло»).

### 6. Новый стиль оформления: Nothing OS
- Добавлен 5-й фирменный стиль: **Nothing OS** (`THEME_NOTHING`):
  - Монохромный контрастный хай-тек (глубокий чёрный, чистый белый, точечный акцент красного глифа Nothing Red `#E50914`).
  - Точечно-матричный технологичный акцент и минимализм.

### 7. Менеджер активных виджетов: кнопка «🗑️ Удалить»
- В разделе «📱 Ваши виджеты на рабочем столе» в `MainActivity` рядом с кнопкой «⚙️ Настроить» добавлена кнопка «🗑️ Удалить».
- Позволяет сбросить изолированную конфигурацию виджета прямо из настроек приложения с диалогом подтверждения.

### 8. Графические силуэты пропорций для добавления виджетов
- Раздел «📌 Добавить виджет на рабочий стол» преобразован в стильную сетку 2×2 карточек.
- Вместо длинных текстовых строк каждая карточка содержит наглядный физический силуэт пропорций виджета (4×2, 4×1, 2×2, 2×1) с миниатюрным превью внутреннего содержимого.

### 9. Очистка интерфейса
- Удалена надпись «Xiaomi HyperOS & Apple iOS Движок» в заголовке настроек.

## 📱 Полная изоляция каждого виджета (Per-Widget Instance Isolation)

- **Уникальные `Uri` и `Action`**: для каждой кнопки ⚙️ на рабочем столе `PendingIntent` получает уникальный `data = Uri.parse("alice://widget/$appWidgetId")` и уникальный `action = "com.alice.homewidget.CONFIGURE_WIDGET_$appWidgetId"`. Это исключило перезапись интентов системой Android при размещении нескольких виджетов.
- **Хранение настроек strictly by `appWidgetId`**:
  - `w_${appWidgetId}_theme` — индивидуальный стиль.
  - `w_${appWidgetId}_dev_ids` — список устройств, привязанных к этому конкретному виджету.
  - `w_${appWidgetId}_title` — индивидуальное название виджета.
- Смена устройств на одном виджете **никогда не затрагивает другие виджеты**!

## 📐 Поддерживаемые форматы виджетов

1. **4 × 2 (Главный смарт-хаб датчиков)**:
   - Заголовок с комнатой и точным временем последнего обновления.
   - Левый отсек: крупная температура, круговой датчик комфорта со статус-бейджем («🌿 Комфортно», «❄️ Прохладно», «🔥 Тепло»), капсулы влажности и давления.
   - Правый отсек: плитки других выбранных комнат, статус дверей («🚪 Закрыто» / «🚪 ОТКРЫТО!»), топливо/батарея.
2. **4 × 1 (Инфо-полоса нескольких комнат)**:
   - Эстетичная полоса с 3 контрастными стеклянными отсеками, крупными цифрами и векторными иконками.
3. **2 × 2 (Климат комнаты)**:
   - Квадратная карточка с большим кольцом комфорта, центральной температурой и бейджем комфорта / влажности.
4. **2 × 1 (Мини-климат)**:
   - Идеально выверенная узкая карточка без наслоений: комната сверху, крупная температура слева, капсула влажности справа.

## 📂 Структура файлов проекта
- `app/src/main/java/com/alice/homewidget/`
  - `AliceApplication.kt` — запуск приложения
  - `api/YandexApiClient.kt` — сетевые вызовы к Yandex IoT API
  - `model/YandexModels.kt` — строгие модели физических характеристик устройств
  - `data/WidgetDataManager.kt` — хранилище настроек по `appWidgetId`, метрики устройств, стили
  - `ui/`
    - `MainActivity.kt` — главный экран, силуэты добавления виджетов, удаление, синхронизация комнат
    - `WidgetConfigureActivity.kt` — экран персональной настройки конкретного экземпляра виджета
  - `widget/`
    - `WidgetRenderEngine.kt` — Custom Canvas Graphics Engine для всех 4 форматов и 5 стилей
    - `AliceHomeWidgetProvider.kt` (4x2)
    - `AliceBarWidgetProvider.kt` (4x1)
    - `AliceCompactWidgetProvider.kt` (2x2)
    - `AliceCompact2x1WidgetProvider.kt` (2x1)
  - `worker/SensorSyncWorker.kt` — фоновое обновление по расписанию
  - `receiver/BootReceiver.kt` — автозапуск после перезагрузки устройства
- `app/src/main/res/`
  - `drawable/`
    - `bg_widget_silhouette.xml` — графический силуэт для карточек добавления виджетов
    - `bg_btn_ripple.xml` — системный ripple-эффект нажатия на хотспоты
    - `bg_skin_*.xml`, `bg_tile_*.xml`, `bg_btn_*.xml` — векторные ресурсы стилей
    - `ic_gear.xml`, `ic_refresh.xml`, `ic_humidity.xml`, `ic_thermometer.xml`, `ic_door.xml`, `ic_pressure.xml`
    - `ic_alice_app_icon.png` — эстетичная иконка приложения в стиле Алисы
  - `layout/` — разметки экранов и виджетов (Canvas ImageView + прозрачные хотспоты)
  - `xml/` — метаданные виджетов с подключением `WidgetConfigureActivity`
- `app/debug.keystore` — постоянный ключ подписи приложения
- `.github/workflows/build-apk.yml` — облачная компиляция APK в GitHub Actions (артефакт `AliceHomeWidget-v0.35-APK`)
