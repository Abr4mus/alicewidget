## 🚀 Новый графический движок и стили оформления (v0.33)

### 1. Движок рендеринга `WidgetRenderEngine`
Вместо примитивных плоских XML-прямоугольников задействован высокоточный графический движок `WidgetRenderEngine`:
- **Динамический круговой датчик комфорта (Comfort Gauge Ring)**: аппаратная отрисовка на Canvas сглаженного кольца комфорта (270° трек, светящаяся градиентная дуга от прохладного синего до комфортного бирюзового и теплого оранжевого, светящаяся точка-индикатор с мягким световым ореолом).
- **Спекулярные световые блики (Specular Highlights)**: стеклянный верхний кант карточек для эффекта глубокого стекла.
- **Интерактивные анимации**: ripple-эффекты при нажатии на плашки и кнопки, динамическая ротация статуса при обновлении данных.

### 2. Стили оформления:
* 🤖 **Xiaomi HyperOS (`THEME_XIAOMI`)**:
  - Обсидиановый полупрозрачный акрил (`bg_skin_xiaomi.xml`), 26dp скругление со сглаживанием кривизны.
  - Двухуровневые матовые плитки (`bg_tile_xiaomi.xml`).
  - Круговой датчик комфорта с неоновым бирюзовым (`#00D2B4`) и оранжевым (`#FF6900`) акцентами.
* 🍏 **iPhone / iOS 17 & 18 (`THEME_IOS`)**:
  - Премиальное глубокое матовое стекло Apple Frosted Glass (`bg_skin_ios.xml`) с непрерывным скруглением **26dp** (Apple squircle).
  - Минималистичная типографика SF Pro, утонченные разделители, Apple system colors (зеленый комфорт, синий акцент).
* 💜 **Яндекс / Алиса Pro (`THEME_ALICE`)**:
  - Космическое фиолетово-сиреневое матовое стекло, неоновые сиреневые рамки, лавандовый свет.

## 📱 Полная изоляция каждого виджета (Per-Widget Instance Isolation)

### Решение проблемы смены устройств на всех виджетах:
- **Архитектура Android `appWidgetId`**: каждому добавленному на рабочий стол виджету присваивается уникальный числовой идентификатор.
- Все настройки (выбранные устройства, привязанная комната, стиль оформления, заголовок) теперь сохраняются **строго по `appWidgetId`** (`WidgetInstanceConfig`).
- **Смена устройств в одном виджете БОЛЬШЕ НИКОГДА не влияет на другие виджеты!**
- **Экран настройки конкретного виджета `WidgetConfigureActivity`**:
  - Зарегистрирован в `AndroidManifest.xml` и объявлен через `android:configure` во всех 4 провайдерах.
  - Автоматически открывается при добавлении виджета на рабочий стол.
  - На каждом виджете есть кнопка ⚙️ (или шестеренка в панели), которая открывает настройку именно этого конкретного экземпляра!
- **Менеджер активных виджетов в `MainActivity`**:
  - Автоматически находит все виджеты, размещенные пользователем на рабочем столе.
  - Отображает их список: `Виджет #14 (4×2) — Стиль Xiaomi`, `Виджет #15 (2×1) — Стиль iOS`.
  - Позволяет в 1 клик перейти к настройке любого из них.

## 📊 Индивидуальные показатели для каждого устройства (Без общих флагов)
- **Удалены все глобальные чекбоксы** («Влажность для всех», «Двери для всех»).
- В настройках каждого устройства отображаются **ТОЛЬКО ТЕ показатели, которые этот датчик реально поддерживает**:
  - Климатический датчик: `[✓] Температура` `[✓] Влажность` `[✓] Давление` (если барометрический)
  - Датчик открытия: `[✓] Статус двери`
  - Датчик протечки: `[✓] Протечка`
  - Беспроводной датчик: `[✓] Заряд батареи`
- Если у датчика нет барометра или влажности, эти пункты даже не появляются в интерфейсе и не выводятся на виджет.

## 📂 Структура файлов проекта
- `app/src/main/java/com/alice/homewidget/`
  - `AliceApplication.kt` — запуск приложения
  - `api/YandexApiClient.kt` — сетевые вызовы к Yandex IoT API
  - `model/YandexModels.kt` — модели данных датчиков
  - `data/WidgetDataManager.kt` — хранилище настроек, изолированное по `appWidgetId`, и индивидуальные показатели устройств
  - `ui/`
    - `MainActivity.kt` — главный экран, менеджер активных виджетов, вход по токену
    - `WidgetConfigureActivity.kt` — Activity персональной настройки конкретного виджета
  - `widget/`
    - `WidgetRenderEngine.kt` — графический движок колец комфорта, акрила и стилей
    - `AliceHomeWidgetProvider.kt` (4x2)
    - `AliceBarWidgetProvider.kt` (4x1)
    - `AliceCompactWidgetProvider.kt` (2x2)
    - `AliceCompact2x1WidgetProvider.kt` (2x1)
  - `worker/SensorSyncWorker.kt` — фоновое обновление по расписанию
  - `receiver/BootReceiver.kt` — автозапуск после перезагрузки
- `app/src/main/res/`
  - `drawable/`
    - `bg_skin_xiaomi.xml`, `bg_tile_xiaomi.xml`, `bg_pill_xiaomi.xml`, `bg_btn_xiaomi.xml`
    - `bg_skin_ios.xml`, `bg_tile_ios.xml`, `bg_btn_ios.xml`
    - `bg_skin_alice.xml`, `bg_tile_alice.xml`, `bg_btn_alice.xml`
    - `ic_gear.xml` — иконка персональной настройки виджета
    - `ic_alice_app_icon.png` — эстетичная иконка приложения
  - `layout/` — разметки экранов и виджетов с поддержкой датчиков комфорта и кнопок шестерёнки
  - `xml/` — метаданные виджетов с подключением `WidgetConfigureActivity`
- `.github/workflows/build-apk.yml` — облачная компиляция APK в GitHub Actions
