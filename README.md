# 🟣 Виджет «Умный Дом Яндекс» (Версия 0.35)

Современный и эстетичный виджет умного дома Яндекс для рабочего стола Android на базе автономного графического движка **Custom Canvas Graphics Engine** (архитектура в стиле Overdrop / KWGT) со стилями **Xiaomi HyperOS**, **Apple iOS 18 Frosted Glass**, **Яндекс / Алиса Pro**, **Android Material You** и **Nothing OS**.

---

### 🆕 Что нового в версии 0.35:

1. **🛠️ Полное устранение бага с центровкой и искажением виджета 2×2**:
   - Исправлена ошибка, из-за которой при настройке виджета 2×2 он ошибочно перезаписывался провайдером 2×1 до изменения размера на рабочем столе. Теперь каждый виджет строго обновляется через собственный провайдер.

2. **🚗 Строгие физические показатели датчиков (включая автомобили)**:
   - Исключены фиктивные показатели: автомобиль и другие неклиматические устройства больше не показывают неработающую влажность.
   - Поддерживаются реальные параметры: температура, влажность, давление, открытие дверей, заряд батареи, уровень топлива/жидкости (`⛽/🔋`) и мощность розеток (`⚡`).

3. **🏠 Группировка по комнатам и двусторонняя синхронизация чекбоксов**:
   - Устройства сгруппированы по комнатам в удобных контейнерах.
   - Главная галочка комнаты автоматически включает/выключает все устройства комнаты.
   - При ручном выборе устройств галочка комнаты обновляется динамически.

4. **✨ Кардинальный редизайн полосы 4×1**:
   - Вместо блеклого мелкого текста — 3 рельефных матовых стеклянных отсека с крупными цифрами и векторными иконками (`🌡️`, `💧`, `🚪`, `🔋`, `⛽`, `⚡`).

5. **🍏 Настоящий Apple iOS 18 Frosted Glassmorphism**:
   - Реалистичное рассеивающее матовое стекло, спекулярная верхняя фаска преломления света и понятные текстовые бейджи шкалы («🌿 Комфортно», «❄️ Прохладно», «🔥 Тепло»).

6. **⚫ Новый 5-й стиль: Nothing OS**:
   - Монохромный контрастный хай-тек в стиле Баухаус с акцентным красным глифом.

7. **🗑️ Удаление виджетов из настроек**:
   - В разделе «Ваши виджеты на рабочем столе» добавлена кнопка «🗑️ Удалить» рядом с «⚙️ Настроить».

8. **📌 Визуальные силуэты пропорций виджетов**:
   - Раздел добавления виджетов преобразован в удобную графическую сетку 2×2 с силуэтами пропорций (4×2, 4×1, 2×2, 2×1).

9. **⚡ Бесшовное обновление**:
   - Постоянный ключ `app/debug.keystore` сохранен — APK устанавливается как прямое обновление поверх предыдущих версий.
