# 🟣 Виджет «Умный Дом Яндекс» в стиле Алисы, Xiaomi и iPhone (Версия 0.33)

Современный и нежный виджет для рабочего стола Android с новым графическим движком в стиле **Xiaomi HyperOS** и **Apple iOS 17/18**, а также **Яндекс / Алиса Pro**.

---

### 🆕 Что нового в версии 0.33:

1. **🚀 Новый движок рендеринга `WidgetRenderEngine`**:
   - **Динамический круговой датчик комфорта**: аппаратная отрисовка на Canvas светящегося кольца уровня комфорта (от прохладного синего до комфортного бирюзового и теплого оранжевого со светящимся индикатором).
   - **Спекулярные стеклянные блики и акрил**: эффект глубокого стекла и отражений света по верхнему канту карточек.
   - **Интерактивные анимации**: плавные ripple-эффекты при нажатии и динамическая индикация обновления.

2. **🤖 Новый флагманский стиль Xiaomi HyperOS**:
   - Обсидиановый полупрозрачный акрил, скругления 26dp со сглаживанием кривизны.
   - Двухуровневые матовые плитки, неоновый бирюзовый (`#00D2B4`) и оранжевый (`#FF6900`) акценты.

3. **🍏 Премиальный стиль iPhone / iOS 17**:
   - Глубокое матовое стекло Apple Frosted Glass с непрерывным скруглением **26dp** (Apple squircle).
   - Минималистичная типографика SF Pro, утонченные разделители, Apple system colors (зеленый комфорт, синий акцент).

4. **📱 Полная независимость каждого виджета (Per-Widget Isolation)**:
   - Каждый добавленный виджет теперь имеет **собственные уникальные настройки**.
   - Смена устройств на одном виджете **больше не меняет устройства на других виджетах**!
   - На каждом виджете появилась кнопка **⚙️**, открывающая персональную настройку именно этого виджета.
   - В приложении появился раздел **«📱 Ваши виджеты на рабочем столе»** со списком всех активных виджетов.

5. **📊 Индивидуальные показатели для каждого устройства**:
   - Полностью убраны общие глобальные переключатели влажности и дверей.
   - Для каждого датчика выводятся только поддерживаемые им величины: Температура, Влажность, Давление (если барометр), Дверь (если геркон), Батарея.

6. **⚡ 1-клик авторизация и бесшовное обновление**:
   - Автоматический перехват токена через встроенный диалог WebView.
   - Обновление поверх старых версий без необходимости переустановки.
