# 🟣 Виджет «Умный Дом Яндекс» в стиле Алисы для Android

Красивый, современный и стильный виджет для рабочего стола Android в фирменном дизайне Алисы (неоновый фиолетовый градиент, эффект матового стекла Glassmorphism, акцентные карточки комнат и датчиков).

---

## ✨ Возможности виджета

1. **Все показания датчиков прямо на рабочем столе**:
   - 🌡️ **Температура** (°C) с цветовой индикацией
   - 💧 **Влажность** (%) с оценкой уровня комфорта
   - 🧭 **Атмосферное давление** (в мм рт. ст.)
   - 🚪 **Датчики открытия дверей и окон** (🟢 *Закрыта* / 🔴 *ОТКРЫТА!*)
   - 🚰 **Датчики протечки воды** (мгновенное оповещение о тревоге)
   - 🔋 **Уровень заряда батареек** в беспроводных датчиках (Zigbee / Wi-Fi)
2. **Поддержка нескольких комнат**:
   - Отображение активной комнаты (например, *Гостиная*) + сводные плашки других комнат (*Спальня*, *Кухня*, *Детская*).
3. **Три формата виджета**:
   - **4 × 2 (Полный хаб)**: максимальная информативность, климат, комнаты, охрана, батарейки и кнопка ручного обновления.
   - **2 × 2 (Климат комнаты)**: компактная карточка с крупной температурой, влажностью и давлением.
   - **4 × 1 (Мини-полоса)**: аккуратная строка статуса дома для размещения вверху или внизу экрана.
4. **Сверхбыстрое и бережное обновление**:
   - Фоновая синхронизация по расписанию через Android **WorkManager** (каждые 15–30 минут, без лишнего расхода батареи).
   - Мгновенное обновление по нажатию на кнопку **🔄** прямо на виджете.
   - Быстрый переход в приложение или «Дом с Алисой» по клику на логотип.

## 🔑 Шаг 1. Получение OAuth-токена Яндекса

Для доступа к показаниям ваших датчиков через официальный Smart Home API Яндекса нужен персональный OAuth-токен с доступом `iot:view`:

1. Перейдите на страницу создания приложений Яндекса: [oauth.yandex.ru/client/new](https://oauth.yandex.ru/client/new)
2. Заполните поля:
   - **Название приложения**: `Виджет Умного Дома`
   - **Платформы**: выберите **«Веб-сервисы»**
   - **Callback URL (Redirect URI)**: введите `https://oauth.yandex.ru/verification_code`
3. В разделе **«Доступы»** найдите блок **«Умный дом (iot)»** и отметьте:
   - `iot:view` — *Просмотр информации об устройствах умного дома*
4. Нажмите внизу **«Создать приложение»**.
5. Скопируйте появившийся **ClientID** (ID приложения).
6. Откройте в браузере ссылку (заменив `ВАШ_CLIENT_ID` на скопированный ID):
   ```text
   https://oauth.yandex.ru/authorize?response_type=token&client_id=ВАШ_CLIENT_ID
   ```
7. Нажмите **«Войти» / «Разрешить»**. На экране отобразится ваш токен (начинается с `y0_...`). Скопируйте его!

## 📲 Шаг 2. Установка на смартфон

### Вариант А. Сборка APK через GitHub Actions (Самый простой способ, без установки Android Studio!)
В этот проект уже включен файл автоматической сборки `.github/workflows/build-apk.yml`:
1. Загрузите файлы этого проекта в ваш репозиторий на [GitHub](https://github.com/).
2. GitHub автоматически запустит сборку в разделе **Actions**.
3. Через 1-2 минуты во вкладке сборки скачайте готовый файл **`AliceHomeWidget-Debug-APK.zip`**.
4. Распакуйте и установите полученный `.apk` на смартфон.

### Вариант Б. Сборка через Android Studio
1. Откройте эту папку в **Android Studio**.
2. Дождитесь синхронизации Gradle.
3. Выберите **Build > Build Bundle(s) / APK(s) > Build APK(s)** либо нажмите зеленую кнопку **Run** при подключенном по проводу телефоне.

## 🚀 Шаг 3. Запуск и добавление виджета

1. Запустите установленное приложение **«Алиса Дом: Виджет»** на телефоне.
2. Вставьте ваш токен и нажмите кнопку **«Синхронизировать и проверить»**.
3. Приложение отобразит список ваших датчиков и подтвердит связь.
4. Выйдите на домашний экран Android, зажмите пустую область экрана и выберите **«Виджеты»**.
5. Найдите **«Алиса Дом: Виджет»** и перетащите виджет желаемого размера (например, **4 × 2**) на рабочий стол.
6. Готово! Все показания датчиков обновляются в реальном времени в стиле Алисы!

## 🎨 Альтернатива: Настройка через KWGT (Kustom Widget Maker)

Если вы предпочитаете настраивать виджеты через популярное приложение **KWGT**:
1. Установите **KWGT Kustom Widget Maker** из Google Play или RuStore.
2. Создайте пустой виджет 4x2.
3. Добавьте текстовый слой с формулой запроса к API Яндекса:
   ```text
   $wg("https://api.iot.yandex.net/v1.0/user/info", json, .devices[?(@.type=~'sensor.climate')].properties[?(@.parameters.instance=='temperature')].state.value)$°C
   ```
   *(Для передачи заголовка авторизации используется связка с HTTP-плагином или Tasker/Macrodroid).*
